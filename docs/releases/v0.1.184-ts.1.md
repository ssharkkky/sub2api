## Upstream Changes

- 基线：`upstream/v0.1.183 (efb46db0a)` → `upstream/v0.1.184 (200602b41)`，共 153 个提交。
- **OpenAI service tier 计费**：出站档位与观察档位分离（outbound / observed），responses & messages chat-fallback 全路径保留 tier；Codex OAuth 凭据观察 `default` 为非权威（保留出站档）；shadow 凭据 tier 契约解析；API key 凭据观察档位可降级计费（本次以渠道开关 opt-in，见 Fork Changes）。
- **TTFT**：指标模式从全局配置迁移到管理端设置（admin settings）。
- **用量/计费**：原生 compaction 请求跟踪（`usage_logs.native_compaction_v2`）；请求推理强度（映射前）展示（`usage_logs.requested_reasoning_effort`）；DeepSeek 计费对齐官方峰谷价；渠道定价对带后缀模型名不再被官方兜底价覆盖。
- **Grok**：`prompt_cache_key` 缓存身份（优先于 `X-Grok-Conv-Id`）；Responses vision tool output 图片保留。
- **管理**：管理员可按用户限制可访问的公开组（`users.restrict_public_groups`）。
- 其余为 openai（22）/ frontend（10）/ grok（6）/ billing 等模块修复与测试加固。

## Configuration And Migrations

- **迁移（3 个新增，纯加列 + 默认值，managed-update 回退兼容，无既有迁移修改）**：
  - `usage_logs.native_compaction_v2 BOOLEAN`（可空 + `reviewed-compatible` `SET DEFAULT FALSE`；历史 NULL 行由应用层映射为 false，"非 compaction"过滤用 COALESCE 命中历史行）

  - 上游原编号 231 系与已发布基线（233，v0.1.183-ts.3）冲突，重命名为 **264/265/266**（内容不变，无代码引用迁移文件名）

  - TTFT 指标模式改由管理端设置配置（上游变更）。
  - 用户级 `restrict_public_groups`（管理端，上游变更）。
- 默认值与 v0.1.183-ts.3 行为对齐，无强制配置项。
