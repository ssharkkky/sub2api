# TokenSupply v0.2.0-ts.1

## Highlights

- 追上上游 `v0.2.0`（53 个上游提交，PR #156 单次 merge 合入，保留上游祖先链）：分组级 Group Fast（`force_openai_fast`）与 Free Fast（`free_openai_fast`）开关、reasoning-effort 超限控制（deny/downgrade）、1h 缓存写入计价（`cache_write_1h_price`）、Fable 5.1 兜底价格。
- Fork 渠道 service-tier 计费权威与上游 Free Fast 正确整合：free 分组的 Fast 请求按 Standard 重定价时透传 fork 渠道 tier 快照，OAuth fast-tier 决策链不变。
- 模型广场长上下文阶梯表由真实计费函数两点探针推导（`ResolveContextPricingSchedule`），断点只取计费自身规则输入，展示与扣费结构上不可能分叉。
- go.sum 清理 4 个死模块条目（PR #157），`go mod tidy` 零漂移，满足发布前置门禁。

- 既有 fork 能力全部保留并经回归：Kiro 平台支持、分组/渠道定价、渠道 service-tier / OAuth fast-tier 计费权威、提示词审计、渠道监控 v2、长上下文统一计费核心（分组开关 + 区间价卡优先 + catalog 字段级 overlay）。

## Deployment And Rollback

- 使用现有 deployer 蓝绿更新即可，不需要停机维护：先跑迁移 267/268/269/270（全部新列，additive），再滚动新镜像。
- 上一完成版本 `v0.1.185-ts.1` 保持回滚兼容：新列可空或有默认值，旧版本不读取。

- 正式 tag 只能由 `Promote Release` workflow 在精确 `main` SHA 通过所有门禁后创建，不手工创建或覆盖。
