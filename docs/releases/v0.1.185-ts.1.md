# TokenSupply v0.1.185-ts.1

## Highlights

- 上游基线推进 `v0.1.184` → `v0.1.185`（23 个上游提交，PR #153 单次 merge 合入，保留上游祖先链）。
- **审计 worker CPU 修复（PR #152）**：`securityaudit.ConfigManager.Active()` 克隆不再每次重建 Aho-Corasick 关键词自动机——生产实测 32 worker × 2Hz × ~6ms/次 ≈ 64 次重建/秒（~0.55 核 + GC 压力），修复后克隆仅共享不可变 matcher 指针（~600× 降幅）。上游同代码存在同样问题。
- 上游长上下文阶梯计价改为价格目录数据驱动（`above_272k_tokens` 目录字段、`override_file` 覆盖补丁、分时倍率）；fork 渠道定价体系完整保留（内部目录 `LockPrice` 仍最后应用，冲突时 fork 价赢）。
- **无新增迁移、无 schema 变化、无强制配置项**；回退到 v0.1.184-ts.1 完全兼容。
