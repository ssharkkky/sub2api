## Known Limitations

- 两个 `234_` 迁移文件并存，属上游/ fork 同号：按文件名排序可正确执行，但阅读时易误以为重复；后续迁移从 235 编号，不做历史重命名。
- Kiro 私网图床行为变化：图片 URL 指向私网/链路本地地址时不再抓取估算，回退固定 token 值（请求不失败，仅精度回退）；需私网放行等 follow-up 的 allowlist 配置项（`NewSSRFSafeClient` 已预留参数）。
- IPv6 过渡机制（6to4 `2002::/16`、NAT64 `64:ff9b::/96`、Teredo `2001::/32`）暂未纳入 SSRF 拦截，当前网络下概率极低，已列入后续加固。
- 渠道 picker 列表变窄为既定目的：以往给“账号还没有的模型”预配定价的习惯改为等 snapshot 覆盖或用「+ Add」手工输入。
- 无 tag 的 `go test ./...` 不含 `unit`/`integration` tag 测试文件；同步/发布验证以 `make test-unit` / `make test-integration` 与 Actions 为准。
