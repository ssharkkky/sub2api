## Deployment And Rollback

- 蓝绿更新即可，无需停机：先跑迁移 276–279（元数据级 / 可重放 / 软删除，无锁表），再滚动新镜像。
- 上一完成版本 `v0.2.2-ts.1` 保持回滚兼容：无 DDL 数据丢弃；279 软删除行对旧版本读取路径同样不可见（`deleted_at` 列与过滤逻辑在旧版本已存在）；回滚 = 镜像回退。回滚后本版能力（零默认路由、白名单删除、WS 池新语义）不可用，既有计费流水与用量记录不受影响。
- 正式 tag 只能由 `Promote Release` workflow 在精确 `main` SHA 通过所有门禁后创建，不手工创建或覆盖；`main` 从本 Release PR 合并到 Promote 完成期间冻结（≤7 天）。
